### 命令介绍 
`git push` 用于将本地分支的提交上传到远程仓库，并更新远程引用（如分支、标签）。它是 Git 协作中的核心命令，支持多种参数控制推送行为、目标地址、分支映射等。

---

### 参数

#### 基本推送参数
- **无参数**  
  推送当前分支到已配置的上游（追踪）远程分支；若未配置上游，则需显式指定。
- `<远程名> <分支名>`  
  将本地指定分支推送到指定远程仓库的同名分支（如 `git push origin main`）。
- `<远程名> <本地分支>:<远程分支>`  
  将本地分支推送到远程的指定分支（名称可以不同，如 `git push origin feature:dev`）。
- `-u` / `--set-upstream`  
  推送当前分支并建立与远程分支的追踪关系（上游），后续可直接用 `git push`。

#### 删除远程分支
- `--delete <远程分支名>`（或 `-d`）  
  删除远程仓库中的指定分支（如 `git push origin --delete feature`）。
- `:<远程分支名>`  
  使用空本地分支语法删除远程分支（如 `git push origin :feature`，等同于 `--delete`）。

#### 强制推送
- `-f` / `--force`  
  强制推送，覆盖远程分支历史（即使远程有本地未知的提交）。**危险操作**，会丢失远程独有提交。
- `--force-with-lease`  
  更安全的强制推送：仅当远程分支与本地预期的远程跟踪分支状态一致时才强制推送（防止覆盖他人新推送的提交）。
- `--force-if-includes`  
  仅当远程分支包含了本地引用中记录的远程提交时才允许强制推送（结合 `--force-with-lease` 使用）。

#### 推送标签
- `--tags`  
  推送所有本地标签（annotated tags）到远程（不推送轻量标签的引用）。
- `--follow-tags`  
  推送当前分支的提交以及所有关联的标签（仅当标签指向被推送的提交时）。
- `--no-tags`  
  不推送任何标签（覆盖默认行为）。

#### 推送策略
- `--all`  
  推送所有本地分支到远程（同名分支）。
- `--mirror`  
  将本地所有引用（包括分支、标签、远程跟踪分支等）推送到远程，**完全镜像**（会删除远程上本地没有的引用）。常用于镜像仓库。
- `--dry-run`（或 `-n`）  
  模拟推送，不实际执行，用于预览将要推送的内容。
- `--prune`  
  删除远程上本地不存在的分支（与推送同步，清理远程已删除的分支）。
- `--atomic`  
  确保推送是原子性的：要么所有引用全部成功推送，要么全部失败（避免部分更新）。
- `--receive-pack=<git-receive-pack>` / `--exec=<git-receive-pack>`  
  指定远程服务器上执行的接收包命令路径（通常用于调试）。

#### 输出
- `-v` / `--verbose`  
  输出详细日志，显示推送过程中的更多信息。
- `-q` / `--quiet`  
  静默模式，不输出任何信息（除非发生错误）。
- `--progress`  
  显示推送进度（默认在交互式终端开启）。
- `--porcelain`  
  输出机器可解析的格式，便于脚本处理。

#### 引用路径
- `--refspec <引用映射>`  
  手动指定推送的引用映射（如 `git push origin +refs/heads/*:refs/heads/*`）。
- `--repo=<仓库>`  
  指定要推送的远程仓库（代替默认远程，可覆盖配置）。
- `--push-option=<字符串>`（或 `-o`）  
  传递选项给远程服务器（如 CI/CD 触发参数），需服务器支持。
- `--signed` / `--no-signed`  
  推送时对提交进行 GPG 签名（或禁用签名），支持 `--signed=if-asked` 按需签名。

#### 其他
- `--thin` / `--no-thin`  
  控制是否使用“瘦”传输（减少数据量），默认开启。
- `--recurse-submodules=<check|on-demand|no>`  
  处理子模块推送策略：`check`（检查子模块提交是否推送）、`on-demand`（自动推送子模块）、`no`（忽略）。
- `--no-verify`  
  跳过推送前的预推送钩子（pre-push hook）检测。
- `--set-upstream`（见基本参数）  
- `--force-with-lease=<refname>`  
  对指定引用使用 `--force-with-lease` 检查（如 `--force-with-lease=main`）。
