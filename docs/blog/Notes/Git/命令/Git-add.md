### 命令介绍
`git add` 用于将工作区中的文件修改添加到暂存区（索引），为下一次提交做准备。它支持添加新文件、已修改文件、删除文件等，并可通过多种参数控制添加范围、交互方式及行为细节。

---
### 参数
#### 基本添加参数
- `<文件或路径>`  
  添加指定文件或目录下的所有变更（如 `git add file.txt` 或 `git add src/`）。
- `.`  
  添加当前目录及子目录下的所有变更（不包括被忽略的文件）。
- `-A` / `--all`  
  添加工作区所有变更（包括修改、删除、新增），等同于 `git add .`（在仓库根目录下）但更彻底（会处理未跟踪的删除）。
- `-u` / `--update`  
  仅添加已跟踪文件的修改或删除，不添加新文件（即更新索引中已有路径）。

#### 交互模式
- `-i` / `--interactive`  
  进入交互式模式，可进行暂存、取消暂存、查看状态、差异比较等操作。
- `-p` / `--patch`  
  进入补丁模式，逐块（hunk）选择要暂存的修改，适用于精细控制部分代码变更。
- `-e` / `--edit`  
  打开编辑器，手动编辑暂存区与工作区间的差异（可直接修改暂存区内容）。

#### 预览/模拟（不实际添加）
- `-n` / `--dry-run`  
  模拟执行添加操作，不实际修改暂存区，仅显示将要添加的文件列表。
- `-v` / `--verbose`  
  输出详细信息，包括添加的文件名称等。

#### 强制
- `-f` / `--force`  
  强制添加被 `.gitignore` 忽略的文件（忽略忽略规则）。
- `--ignore-errors`  
  跳过因错误（如文件读取失败）而中断的操作，继续处理其他文件。
- `--ignore-missing`  
  忽略由于文件缺失导致的错误（通常与 `--dry-run` 配合用于检查）。
- `--no-warn-embedded-repo`  
  添加子仓库时，不显示警告信息。

#### 索引刷新
- `--refresh`  
  不实际添加文件，仅刷新索引（更新文件状态，如修改时间），用于检查未暂存的变更。
- `--renormalize`  
  根据当前配置的换行符和属性重新规范化文件，并暂存结果。

#### 文件元数据
- `--chmod=<(+|-)x>`  
  添加后设置可执行权限（如 `--chmod=+x` 添加可执行位），常用于脚本文件。

#### 路径规范
- `--pathspec-from-file=<文件>`  
  从指定文件读取路径列表（每行一个），替代命令行参数。
- `--pathspec-file-nul`  
  与 `--pathspec-from-file` 配合，使用 NUL 字符（`\0`）作为路径分隔符（支持空格和换行的路径）。

#### 特殊
- `-N` / `--intent-to-add`  
  仅记录文件将被添加的意图（用于跟踪未跟踪文件，但暂存区不包含内容），常用于提前查看差异（`git diff` 会显示空文件）。
