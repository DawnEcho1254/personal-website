Git-clone

2026-08-18

命令介绍

git clone 用于将远程 Git 仓库复制到本地，创建本地工作目录并初始化版本历史。它默认会设置远程跟踪关系（origin），并检出默认分支的工作文件。支持多种参数控制克隆深度、分支、协议行为等。

参数

基本

  • <仓库地址>
    指定要克隆的远程仓库 URL（HTTPS/SSH/git 协议等）。
  • <目录>
    指定本地目标目录名（默认为仓库名），用于存放克隆内容。
  • --local（或 -l）
    从本地仓库克隆，使用硬链接节省空间（避免直接复制对象）。
  • --no-hardlinks
    强制复制对象文件而不使用硬链接（即使 --local 生效时也禁用）。

分支检出选项

  • --branch <分支名>（或 -b）
    克隆后立即切换到指定分支（而非默认分支），可以是分支、标签或提交哈希。
  • --single-branch
    仅克隆指定分支的历史，不拉取其他分支引用（节省时间和空间），常与 --branch 配合。
  • --no-single-branch
    取消 --single-branch 影响，克隆所有分支（默认行为）。
  • --depth <深度>
    创建浅克隆（shallow clone），仅拉取最近的指定提交数量，减少历史体积。
  • --shallow-since=<日期>
    浅克隆，仅拉取指定日期之后的提交历史。
  • --shallow-exclude=<修订版本>
    浅克隆，排除指定修订版本及之前的提交历史。
  • --unshallow
    将浅克隆转换为完整仓库，拉取所有历史（在已有浅克隆上执行）。
  • --no-checkout
    克隆完成后不检出工作目录文件（只创建 .git 目录，可用于后续手动检出）。
  • --filter=<过滤器>
    部分克隆，按需加载对象（如 --filter=blob:none 只拉取提交历史，不拉取文件内容）。

远程跟踪配置

  • --origin <名称>（或 -o）
    自定义远程仓库的别名（默认为 origin）。
  • --remote
    使用 --upload-pack 指定远程包传输命令（较少用，用于调试）。
  • --upload-pack <路径>
    指定远程服务器上 git-upload-pack 的命令路径。

模板/配置

  • --template <模板目录>
    使用指定模板目录初始化 .git 目录（可包含钩子、描述等默认文件）。
  • --config <键>=<值>（或 -c）
    在克隆仓库中设置 Git 配置项（可多次使用）。
  • --separate-git-dir <目录>
    将 .git 目录放到指定位置，并在工作目录用 .git 文件链接到它（用于分离仓库内容）。

传输协议

  • --protocol <协议>
    强制使用指定的传输协议（如 ssh、https、git 等）。
  • --depth 与 --shallow-* 也影响传输量（见上）。
  • --progress
    强制显示克隆进度（即使非交互式终端）。
  • --quiet（或 -q）
    静默模式，不输出任何信息（错误除外）。
  • --verbose（或 -v）
    显示详细过程信息（可重复使用）。

操作行为控制

  • --bare
    创建裸仓库（只有 .git 内容，无工作目录），通常用于服务器端镜像。
  • --mirror
    创建镜像仓库（与 --bare 类似，但会设置远程跟踪引用，用于完整备份）。
  • --dissociate
    克隆时仅从备用对象目录（--reference）引用对象，克隆后解除关联（节省磁盘）。
  • --reference <本地仓库>
    使用指定本地仓库作为对象引用（节省网络传输和磁盘空间）。
  • --reference-if-able <本地仓库>
    同 --reference，但如果找不到则忽略而不报错。
  • --recurse-submodules[=<策略>]
    初始化并克隆仓库中的所有子模块（可按指定策略：yes、on-demand、no）。
  • --shallow-submodules
    对子模块也执行浅克隆（与 --depth 类似）。
  • --jobs <数量>（或 -j）
    并行克隆子模块的数量（默认不并行）。

钩子/检查

  • --no-tags
    克隆时不拉取远程标签（只拉取分支历史）。
  • --bare 与 --mirror 会默认禁用标签拉取（见上）。
  • --sparse
    启用稀疏检出模式，初始时仅检出顶级目录（需后续配置稀疏规则）。
  • --filter=blob:none 属于部分克隆，可减少下载数据（配合 Git LFS 等）。

其他

  • --git-dir <路径>
    指定 .git 目录的位置（覆盖默认）。
  • --work-tree <路径>
    指定工作目录的位置（覆盖默认）。
  • --exec-path <路径>
    指定 Git 可执行文件的路径（用于调试）。
  • --help
    显示帮助信息。
